# SAT Quest 🚀

Gamified SAT prep that feels like a game, not homework.

**Live at:** `sat.antoniosmith.xyz`

## Features
- 📖 **3 Worlds** — Reading, Writing & Math with 10 difficulty levels each
- ⚡ **Bite-sized** — 5-15 minute practice sessions
- 🔥 **Streaks** — Daily practice tracking
- 🏆 **XP & Levels** — Gamified progression
- 📝 **Review** — See past answers and explanations
- 🎯 **Daily Challenge** — 5 questions per day to maintain streaks

## Tech Stack
- **Frontend:** Pure HTML/CSS/JS (no framework)
- **Backend:** Convex (real-time database)
- **Hosting:** Netlify

## Setup
```bash
bun install
bunx convex dev    # deploy backend
bunx serve .       # serve locally
```
